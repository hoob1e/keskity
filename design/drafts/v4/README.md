## What changed

- A diffuse tint sits behind the main content and fades into the page. One intensity slider controls it along with the Resume and card glows. At **0%**, the effects disappear. The sidebar keeps its own color.
- The glow control shows one percentage, without duplicate endpoint labels. Finish confirmation buttons use matching widths and centered labels. The result omits Import and the extra marking note, while keeping the **Provisional** badge and marking sources.
- **Aa** opens Reading. Font, text size, line spacing, and line width apply to questions and answers, not to navigation or the timer.
