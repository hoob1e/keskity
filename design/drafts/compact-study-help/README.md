# Compact Study help · Layout draft

[White · Violet](white-violet.png) · [Graphite](graphite.png)

Select text to open just **Explain · Definition · Translation** beside the highlight. Choosing a tab opens its body below the same row. There’s no visible title or repeated selection. When the popup reaches the available height, the tabs stay visible and the body scrolls.

- **Explain:** Open the local question field or preview the copyable prompt. A blank question asks about the selection as written. Copying does not send anything.
- **Definition:** Keep the pack’s definition, example, and Ask further when provided. Show generated definitions separately as **Unreviewed**. **Check online** is shown for placement only; online lookup is deferred.
- **Translation:** Keep the pack’s translation when available. Pick a target language and press **Translate** to generate a separate, **Unreviewed** result.

These are the approved static mockups. See [Build 08](../../build-08/README.md) for the live menu and review instructions.
